# 19.10.2026 — уведомление о превышении контекстного лимита

## Изменения
- При постоянной ошибке `provider_context_budget_exceeded` экспертный worker вызывает result-aggregator для доставки понятного сообщения пользователю в Telegram.
- Result-aggregator обрабатывает этот отдельный сценарий, не меняет статус задачи `failed` и записывает подтверждение доставки в `task_events`.
- Добавлены события `task_failure_notified` и `task_failure_notification_failed` для наблюдаемости результата уведомления.

## Проверки
- Проверены изменённые участки исходного кода и переходы статусов по GitHub diff.
- Deno type-check, интеграционные тесты и проверка в отдельной тестовой среде ещё не выполнены.
- Production Edge Functions не развёртывались.

## Ограничения
- Доставка уведомления зависит от доступности Telegram API и настроенного `TELEGRAM_BOT_TOKEN`.
- При ошибке доставки записывается событие ошибки; автоматическая повторная доставка отдельным механизмом в этой фазе не реализована.
