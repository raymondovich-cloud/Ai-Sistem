# Фиксация Idea Vault

- Дата: 07.10.2026
- Изменённый файл: `docs/founder-archive/product-vision.html`
- Идея: контур Idea Vault для сохранения идей через Telegram и Supabase с последующим запуском через Coordinator и специализированных агентов.
- Архитектура: Supabase — источник истины; Telegram — интерфейс и визуальный журнал; Ai-Sistem — оркестрация и выполнение.
- Жизненный цикл: NEW → ANALYZED → APPROVED → IN DEVELOPMENT → DONE / ARCHIVED.
- Статус: стратегическая архитектурная концепция; реализация пока не запускалась.
- Правило: идея не становится задачей разработки автоматически и не должна отвлекать от текущего приоритета LifeGame.
